# Weather App using Flutter with Gemini API Integration

## Course
Mobile Application Development

## Assignment
Weather App using Flutter with Gemini API Integration

## Description
This project is a simple weather application developed using Flutter and Dart. The application fetches real-time weather data using a weather API and displays temperature, weather condition, and location.

The project also includes an AI-based assistant feature using Gemini API. The assistant provides basic weather-related advice to users, such as whether they should go outside or carry an umbrella based on current weather conditions.

## Features
- Real-time weather data
- Current location detection
- Temperature display
- Weather condition display
- Gemini AI weather assistant
- Simple Flutter UI

## Technologies Used
- Flutter
- Dart
- OpenWeather API
- Gemini API
- GitHub
